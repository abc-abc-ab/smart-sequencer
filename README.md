# Smart Sequencer

This extension automatically modifies and inserts sequential numbers, "reading the situation."<br />
「空気を読んで」連番を修正・挿入する拡張機能です。

## Main Features / 主な機能
- **Modification Nums**: Modifies numbers (decimal, hexadecimal, bit shifts) within a selected range into sequential numbers.<br />
**Modification Nums**: 選択範囲内の数字（10進数、16進数、ビットシフト）を連番に修正します。
- **Smart Detection**: Automatically detects the presence or absence of 0x, case sensitivity, padding (e.g., 001), and arithmetic/geometric sequences.<br />
**Smart Detection**: 0xの有無、大文字/小文字、パディング（001など）、等差・等比数列を自動で判別します。
- **Insert Nums**: Inserts sequential numbers in bulk at multiple cursor positions.<br />
**Insert Nums**: マルチカーソル位置に連番を一括挿入します。

## How to Use / 使い方
1. Select the range containing numbers.<br />
数字が含まれる範囲を選択。
2. Execute `Modification Nums` from the right-click menu or `Ctrl+Shift+P`.<br />
右クリックメニューまたは `Ctrl+Shift+P` から `Modification Nums` を実行。
